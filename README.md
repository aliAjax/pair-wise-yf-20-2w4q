# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 风险例外审批

冲突分三类：

- **人员密集区**：燃放点落入密集区覆盖范围，**不得申请例外**，只能改点或取消。
- **同点位间隔**：同一点位相邻两次点火间隔不足最小安全间隔。
- **引信越段**：点火窗口越过所属节目段落结束点。

可例外的两类申请时必须填写**安全负责人、例外理由、失效时刻**（不得晚于整场结束 04:00.000）；同一冲突已有待审或有效例外时不能重复提交。审批记录区分**待审 / 有效 / 失效 / 驳回**，仅**有效**例外可解除放行阻塞。节点的音乐点、发射角或安全距离变化后，绑定的待审/有效例外**立即失效并恢复阻塞**；超过失效时刻同样自动失效。时间轴、点位平面图与冲突清单随状态同步刷新。

代码按三层拆分：

- `src/model.ts` — 业务模型、种子数据、时间工具、localStorage 持久化
- `src/rules.ts` — 冲突判定、例外指纹与生命周期、放行阻塞计算（纯函数）
- `src/App.tsx` — 交互界面（时间轴 / 点位图 / 冲突清单 / 审批记录 / 节点表）

数据仅保存在浏览器 localStorage，无额外依赖与服务端。
